# 分级分层依据索引

按一类 / 二类 / 三类组织，每格给出**条款出处**和**我们手上有没有原件**。

条款文字均取自 `text/P-001-nrta-order-16.txt` 与 `text/P-002-nrta-2024-35.txt`，
两份都是 `manifest.json` 里 `official_primary` 的一手件，带 sha256。金额门槛不在
《办法》里——总局令第16号第五条只说"按投资额度、题材等分"，不给数字，数字在下位
的调整通知中，见 R-001 / R-002。

术语对照：总局令第16号用**一类 / 二类 / 三类**；广电办发〔2024〕35号及调整通知用
**重点 / 普通 / 其他**。同一套分层，两套叫法。《办法》2026-09-01 施行。

## 一类微短剧（重点微短剧）

**入档**：投资额度达到 300 万元及以上，**或**主要剧情涉及政治、军事、外交、国家
安全、统战、民族、宗教、司法、公安等特殊题材。任一条件即可。
另有两条与钱无关的触发（35号）：平台招商主推或首页首屏推荐、自愿按重点申报。

| 环节 | 依据 | 要点 |
|---|---|---|
| 分类 | 令16 第五条 | 按投资额度、题材分类 |
| **拍摄前** | 令16 **第十二条** | 拍摄制作**之前**应当向省级以上申请备案公示 |
| 申报资格 | 令16 **第十四条** | 申请机构应当**持有《广播电视节目制作经营许可证》**或为依法设立的播出机构 |
| 申报材料 | 令16 第十四条 | 《微短剧备案公示申请表》＋剧情梗概等 |
| 特殊题材 | 令16 第十四条二款 | 主管部门认为确有必要的，应当征求有关方面意见 |
| **拍摄中** | 令16 **第十六条** | 应当按备案内容拍摄；变更**主要人物定位、故事整体走向**须**重新备案**；变更剧名、制作机构须办变更 |
| 播出前 | 令16 第十七条 | 申请内容审核和发行许可 → 《微短剧发行许可证》 |
| 送审材料 | 令16 **第十九条** | 报审表／制作经营许可证／样片／字幕表／境外人员批准文件复印件 |
| 时限 | 令16 第二十条 | 受理起 **20 日内**作出决定 |
| 报到哪一级 | 35号 一(1)，调整通知确认 | **国家广电总局**统一备案公示管理 |

**已有原件**：P-001、P-002、R-001
**缺**：《微短剧备案公示申请表》《一类微短剧报审表》空白表。这两份是《办法》配套
新表，不在公开下载页；据备案系统说明，表在系统内取，而系统**不开放注册**，需属地
广电局开通账号。

## 二类微短剧（普通微短剧）

**入档**：投资额度 100 万元（含）至 300 万元之间，且为一般题材。

| 环节 | 依据 | 要点 |
|---|---|---|
| 分类 | 令16 第五条 | 投资额度相对不大且为一般题材 |
| 拍摄前 | 令16 **第十二条** | 「**可以**参照适用」一类的备案公示制度——**不是应当** |
| 细则归属 | 令16 **第十三条**末 | 二类**可以参照本办法制定本行政区域内的备案公示实施细则** |
| 播出前 | 令16 第十七条 | **应当**向省级以上申请内容审核 → **批准文件**（非许可证） |
| 审批方式 | 令16 **第二十四条** | 省级以上**参照**本办法实施审批，鼓励根据本地区实际调整 |
| 播出约束 | 令16 第三十一条 | 应当按许可通过的内容播出 |
| 报到哪一级 | 35号 一(1) | **省级以上**广电主管部门 |

**申报资格**：第十四条的持证要求**只写了一类**。二类在国家层面留白，落到省级细则。
不要替用户断言。

**已有原件**：P-001、P-002、R-001
**缺**：**省级二类备案公示实施细则**。截至 2026-08-27 检索不到任何一省的细则——
《办法》2026-09-01 才施行，各省尚未出台。这一格短期内只能答"依国家条款，省级细则
待出"。

## 三类微短剧（其他微短剧）

**入档**：投资额度不足 100 万元，且为一般题材。

| 环节 | 依据 | 要点 |
|---|---|---|
| 分类 | 令16 第五条 | |
| 备案公示 | —— | **无**拍前备案义务 |
| 播出前 | 令16 第十七条末 | 由符合条件的**播出单位**履行内容管理职责，播前审核并标注节目编号 |
| 平台义务 | 令16 **第三十四条(二)** | 播前审核，并**同步将剧目信息和节目编号在线上系统报广电主管部门** |
| 非独播 | 令16 第三十四条(二) | 各播出单位标注**本单位**编号，**不得使用其他平台的编号** |
| 重新播出 | 令16 **第三十五条** | 应当依照本办法审核标准**重新审核** |
| 报到哪一级 | 35号 一(1) | **平台**自审，平台定期报属地省级广电备案 |

**已有原件**：P-001、P-002
**缺**：平台现行审核标准全文。抖音开放平台 2024-05-31《微短剧类小程序接入内容备案
审核公告》可查，但其门槛仍是 35 号的旧值（100万/30万），**已被调整通知取代**——
与 SRC-005 松江指引同一情况：机制可用，数字不可用。各平台完整规范多在创作者后台或
版权中心，需登录。

## 一句话结论

**做 demo 不缺法条。** 三个档位的判定依据、申报层级、时间顺序都能从 P-001 + P-002 +
R-001 完整引出来，且都是一手或可核验的转述。

**缺的是每档的操作件**：一类缺两张表，二类缺省级细则（客观上还不存在），三类缺平台
现行标准。三样都拿不到公开原件，需要账号或对接人。
