# inbox — 新材料丢这里

拿到任何政策文件、表格、平台规范、办事指南，**原样丢进这个目录就行**，不用改名、
不用整理、不用管格式。

## 你要做的

1. 文件拖进 `docs/policy-library/inbox/`
2. 在这里的 `NOTES.md` 里写一行：这是什么、哪来的、什么时候拿的
   （拿不准就写"不知道"，比猜好）

就这些。

## 我会做的

- 算 `sha256`，防止以后被人悄悄换掉
- 抽文本到 `text/`，这样条款可以被引用和比对
- 判定位阶：`official_primary` / `republication` / `operational` / `forms` /
  `reference-only`——转述不会被当成原件
- 登记进 `manifest.json`
- 按一类 / 二类 / 三类归到 `BY-TIER.md` 对应格子
- 如果它能取代某个转述件，把 `MISSING.md` 里对应项标记为已解决
- 如果它和现有数据冲突，**报出来**，不会默默覆盖

## 格式

都行：PDF、HTML、DOCX、图片、截图。**优先原件**，截图只在拿不到原件时用。

- **网页**：直接把 URL 写进 `NOTES.md`，我自己抓，不用你存
- **要登录才能看的**（平台后台、备案系统内页）：浏览器「另存为网页(单个文件)」
  或「打印成 PDF」，然后丢进来
- **别处理**：不用转格式、不用 OCR、不用删水印。原样最好，水印和收文章反而是
  流转证据

## 一条提醒

如果文件里有你的账号、手机号、身份证号、公司内部批注——**告诉我一声**，我会在
登记前处理掉。这个目录会进 git。
