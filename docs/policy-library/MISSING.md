# 还缺的原始文件

按优先级排列。每一项写明为什么要、现在用什么顶着、去哪里找。

拿到之后放进 `primary/`，在 `manifest.json` 里登记，并把对应的
`republication/` 条目标记为已被原文取代。

## P0 — 系统正在用的数字，目前只有转述

### M-001 《关于调整微短剧分类分层标准的通知》

- **要它做什么**：300万 / 100万 门槛的**原始通知**。2026-01-01 施行。
- **现在用什么顶着**：`republication/R-001` — 宝鸡市文旅局的转述页。
- **为什么必须拿到**：这是系统里唯一一处"钱决定档位"的依据，而依据是二手的。
  同一个转述页里「300万元及以上」和「300万元以上」两种写法都出现过。
- **去哪里找**：
  - 总局官网 `nrta.gov.cn` → 政策文件 / 通知公告 → 站内搜「分类分层」
  - **更快**：直接问宝鸡市文旅局。那页标注「来源：国家广播电视总局」，
    他们手上应该有原文或文号。
  - 任何省级广电局的备案办事指南，「设定依据」一栏通常会引用文号。
- **一句话就能问的替代方案**：如果拿不到原文，问合作方
  「300万元以上是否含300万元本身」。见下面「已经不那么急的两件事」。

### M-002 《管理提示（AI微短剧分类分层标准）》

- **要它做什么**：80万 / 30万 门槛原文。
- **现在用什么顶着**：`republication/R-002` — 西藏网信办转述页。
- **已知信息**：**广电总局网络视听司 2026-06-25 发布**，2026-07-01 施行。
- **去哪里找**：总局官网 → 网络视听司 → 「管理提示」栏目。
  转述页写明「文章来源：广电总局」。
- **注意**：转述页里的表述本身是清楚的（「达到80万元及以上」「30万元（含）至
  80万元之间」），没有歧义。缺的只是原文本身。

## P1 — 影响流程和表单

### M-003 国产网络剧片发行许可 全国实施规范

- **要它做什么**：`P-003`（广电办发〔2022〕128号）第二条说，各省级部门
  **应依照实施规范**制定办事指南。这份是全国统一底稿。
- **为什么要**：现在 `p4_process_templates` 的步骤来自上海和北京。有了实施规范
  才能判断哪些步骤是全国的、哪些是地方的——也就是能不能去掉快照里那句
  `jurisdiction_note`。
- **去哪里找**：总局官网；或省局办事指南的「设定依据 / 法律依据」一栏。

### M-004 《国产网络剧片发行许可证》办事指南

- **要它做什么**：`O-001`（松江指引）里发现，**投资额 100 万元以上的网络微短剧，
  上线播出前需要取得《国产网络剧片发行许可证》**。
- **为什么重要**：这是和分类分层**完全不同的一条线**，产品目前完全没有。
  一个 150 万的项目，系统会告诉他「T2，走省级备案」，
  但不会告诉他上线前还需要发行许可证。
- **去哪里找**：上海「一网通办」、北京市政务服务网、各省局政务服务频道。

### M-005 备案系统的真实表单字段

- **要它做什么**：`p5_form_templates.required_facts` 现在是推测的。
- **去哪里找**：**只能从已登录的「重点网络影视剧信息备案系统」里导出或截图。**
  需要合作方帮忙。空白公开表 `F-002`、`F-003` 只覆盖承诺书和成本配置报告，
  不是备案系统里的字段。

## P2 — 内容审核口径

### M-006 《网络视听节目内容审核通则》

- **要它做什么**：`O-001` 引用它作为内容标准之一。补充 p2 的判定口径。
- **现在有什么相近的**：`P-005`《网络短视频内容审核标准细则（2021）》已经收录，
  但那是短视频的细则，不完全等同。
- **去哪里找**：中国网络视听节目服务协会。

### M-007 《广播电视节目制作经营许可证》办事指南

- **要它做什么**：`O-001` 说这是**前置资质**——没有这个证连制作经营都不合规。
  产品目前完全没提。
- **去哪里找**：各省局政务服务。

## 已经不那么急的两件事

拿到 `P-002`（广电办发〔2024〕35号）之后，有两个原本列为必答的问题已经有依据了：

1. **边界含不含本数**。35 号原文用的是「总投资额度达到 **100万元及以上**」和
   「总投资额度在 **30万元（含）**—100万元之间」。2026 年的调整通知沿用同一套
   写法。两份文件都用「及以上」和「（含）」，说明这套表述习惯是一致的，
   代码里的 `>=` 有依据。**仍建议向合作方确认一句**，但不再是拦路的问题。

2. **特殊题材命中后怎么处理**。35 号写明「对重大题材或者涉及政治、军事、外交、
   国家安全、统战、民族、宗教、司法、公安等特殊题材的微短剧，
   **按有关协审工作机制落实审核要求**」。这比总局令第16号第十四条
   「认为确有必要时征求意见」明确得多，说明特殊题材走协审是有依据的。

## 顺带发现：35 号说明我们的档位模型缺了两个条件

`P-002` 里「重点微短剧」是**符合下列条件之一**：

1. 符合特殊题材 ✅ 已实现
2. 总投资额度达到门槛 ✅ 已实现
3. **长短视频平台招商主推，或在各终端首页首屏推荐播出** ❌ 没有
4. **自愿按重点微短剧申报** ❌ 没有

也就是说，一个 50 万元的普通题材微短剧，只要平台把它放到首页首推，
就应该按重点微短剧处理——系统现在会判成 T3。

这不需要新文件，只需要在 intake 里多问两个问题。
