## P0 — 系统正在用的数字，目前只有转述

### M-001 《关于调整微短剧分类分层标准的通知》

- **要它做什么**：300万 / 100万 门槛的**原始通知**。2026-01-01 施行。
- **现在用什么顶着**：`republication/R-001` — 宝鸡市文旅局的转述页。
- **为什么必须拿到**：这是系统里唯一一处"钱决定档位"的依据，而依据是二手的。
  同一个转述页里「300万元及以上」和「300万元以上」两种写法都出现过。
- **去哪里找**：
  - 总局官网 `nrta.gov.cn` → 政策文件 / 通知公告 → 站内搜「分类分层」
  - **更快**：直接问宝鸡市文旅局。那页标注「来源：国家广播电视总局」，
    他们手上应该有原文或文号。
  - 任何省级广电局的备案办事指南，「设定依据」一栏通常会引用文号。
- **一句话就能问的替代方案**：如果拿不到原文，问合作方
  「300万元以上是否含300万元本身」。见下面「已经不那么急的两件事」。

**2026-08-27 检索结论：公开渠道拿不到，暂不再找。**

- 站内限定 `nrta.gov.cn` 搜「微短剧 分类分层标准 调整 通知」，返回的是 35 号、
  总局令第16号、征求意见稿、微短剧+、精品创作计划——**没有这一份**。
- 公开能找到的全是转述：宝鸡市文旅局、中国网络视听节目服务协会、中广互联、
  律所简报。均无文号。
- 原因是位阶：这类文件属**部门规范性文件**，没有强制集中公开的要求。
  `flk.npc.gov.cn` 只收法律、行政法规、地方性法规、司法解释，不收「广电办发」。
  所以"找不到"不是没找着，是制度上就可能没公开过全文。
- **因此本项不再作为阻塞项**。原目标"拿到原始通知"可能永远达不成，改为：
  拿到**文号** + 一份比市级更权威的转述（协会或北大法宝／威科先行等商业库）。
- **当前处置：照 R-001（宝鸡转述）执行**，即 T1 300万、T2 100万，
  `thresholds_published: true` 保持不变。这是目前证据链最完整的可用值，
  且总局令第16号第五条本身不含数字，数字必须来自下位文件。
- **待问影视行业的朋友**（人的问题，不是检索问题）：
  1. 这份调整通知的**文号**是什么？
  2. 「300万元以上」是否含 300 万本身？（同一转述页两种写法都出现过）
  3. 有没有内部流传的红头件扫描件？

## P1 — 影响流程和表单

### M-003 国产网络剧片发行许可 全国实施规范

- **要它做什么**：`P-003`（广电办发〔2022〕128号）第二条说，各省级部门
  **应依照实施规范**制定办事指南。这份是全国统一底稿。
- **为什么要**：现在 `p4_process_templates` 的步骤来自上海和北京。有了实施规范
  才能判断哪些步骤是全国的、哪些是地方的——也就是能不能去掉快照里那句
  `jurisdiction_note`。
- **去哪里找**：总局官网；或省局办事指南的「设定依据 / 法律依据」一栏。

### M-004 《国产网络剧片发行许可证》办事指南

- **要它做什么**：`O-001`（松江指引）里发现，**投资额 100 万元以上的网络微短剧，
  上线播出前需要取得《国产网络剧片发行许可证》**。
- **为什么重要**：这是和分类分层**完全不同的一条线**，产品目前完全没有。
  一个 150 万的项目，系统会告诉他「T2，走省级备案」，
  但不会告诉他上线前还需要发行许可证。
- **去哪里找**：上海「一网通办」、北京市政务服务网、各省局政务服务频道。

### M-005 备案系统的真实表单字段

- **要它做什么**：`p5_form_templates.required_facts` 现在是推测的。
- **去哪里找**：**只能从已登录的「重点网络影视剧信息备案系统」里导出或截图。**
  需要合作方帮忙。空白公开表 `F-002`、`F-003` 只覆盖承诺书和成本配置报告，
  不是备案系统里的字段。

### M-008 成本配置比例报告的**依据**，以及纯 AI 剧怎么适用

- **要它做什么**：我们在 `grouped_document_requirements` 里要求提交
  `cost_ratio_report`，`F-003` 也是真实公开表。但**库里没有任何条款说这个要求
  从哪来**——`P-003`（广电办发〔2022〕128号）全文 85 行，检索不到「演员」
  「成本」「配置」任何一处。也就是：我们要一份文件，却拿不出要它的依据。
- **还缺的具体数字**：业内通行的「全部演员总片酬不超过制作总成本 40%、主要演员
  片酬不超过总片酬 70%」这两个上限，出处不在库里任何一份文件中。
- **现在用什么顶着**：`F-003` 表格本身（上海门户模板）。表在，依据不在。
- **AI 微短剧的空白**：`F-003` 的字段是总投资额、演员总片酬、片酬占比、男一号
  女一号男二号女二号各自片酬、主要演员占总片酬比例。**纯 AI 无真人出演时这些字段
  没有对应物**。而 `R-002`《管理提示（AI微短剧分类分层标准）》全文只讲三档门槛，
  一个字都没提成本配置或片酬——它反而说 AI「较大地降低了制作成本」，这正是下调
  门槛的理由。所以监管清楚 AI 剧成本结构不同，但**没有说这份报告要不要交、怎么填**。
- **要问的三个问题**（人的问题，检索答不了）：
  1. 40% / 70% 这两个上限的**文号**是什么？
  2. 纯 AI 微短剧**要不要**交成本配置比例报告？
  3. 如果要交，配音演员报酬、真人肖像/数字人授权费、动捕演员报酬，算不算「演员片酬」？
- **对产品的影响**：`is_ai_generated=true` 时仍要求填「男一号片酬」是错的体验，
  且可能是错的要求。在拿到答复前，该字段组应标记为需人工确认，而不是照常追问。

## 已经解决的

**快照生效日与 SRC-001 冲突** — 已解决，见 D-028。快照的 `effective_from` 回答的是
「这份快照从什么时候起可以使用」，条文的生效日是条文自己的属性。两者现在分开记录：
Order 16 的条文标 2026-09-01，门槛条文标 2026-01-01 / 2026-07-01。引用了尚未生效条文的
判断会带 `clause_not_yet_in_force` 标记。

## 已经不那么急的两件事

拿到 `P-002`（广电办发〔2024〕35号）之后，有两个原本列为必答的问题已经有依据了：

1. **边界含不含本数**。35 号原文用的是「总投资额度达到 **100万元及以上**」和
   「总投资额度在 **30万元（含）**—100万元之间」。2026 年的调整通知沿用同一套
   写法。两份文件都用「及以上」和「（含）」，说明这套表述习惯是一致的，
   代码里的 `>=` 有依据。**仍建议向合作方确认一句**，但不再是拦路的问题。

2. **特殊题材命中后怎么处理**。35 号写明「对重大题材或者涉及政治、军事、外交、
   国家安全、统战、民族、宗教、司法、公安等特殊题材的微短剧，
   **按有关协审工作机制落实审核要求**」。这比总局令第16号第十四条
   「认为确有必要时征求意见」明确得多，说明特殊题材走协审是有依据的。

## 顺带发现：35 号说明我们的档位模型缺了两个条件

`P-002` 里「重点微短剧」是**符合下列条件之一**：

1. 符合特殊题材 ✅ 已实现
2. 总投资额度达到门槛 ✅ 已实现
3. **长短视频平台招商主推，或在各终端首页首屏推荐播出** ❌ 没有
4. **自愿按重点微短剧申报** ❌ 没有

也就是说，一个 50 万元的普通题材微短剧，只要平台把它放到首页首推，
就应该按重点微短剧处理——系统现在会判成 T3。

这不需要新文件，只需要在 intake 里多问两个问题。

## M-009 · 二类微短剧的审批时限

总局令第16号第二十条写明一类微短剧“自受理之日起二十日内作出决定，其中组织专家评审的时间为十日”。
**二类没有对应条款。** 三类是平台自审，本来就不走行政审批，不存在法定时限。

想知道的：省级主管部门审二类微短剧实际要多久？是否有省级办事指南写了承诺时限？

为什么重要：想法阶段的预算对照表（D-055）有一栏是“他们多久给答复”。
一类能写 20 日，二类只能写“未规定”。这是诚实的，但对正在定预算的人来说是个空格。
拿到来源就能填上，拿不到就继续空着——不估。
