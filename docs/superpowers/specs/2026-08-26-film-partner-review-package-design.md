# 影视伙伴政策数据复核材料包设计

**日期：** 2026-08-26

**状态：** 已确认，待生成

**负责人：** Richard

## 1. 目标

生成一套影视业务人员可直接阅读和回填的中文材料，用于复核当前
Policy Snapshot v2 中的候选政策数据。材料只服务于人工确认，不替代
官方文件、法律意见或主管部门决定。

当前 v2 保持 `mock_verified`。所有复核项初始为“待确认”；仅当完整清单
经人工确认、证据留档并重新通过技术验证后，才另行决定是否升级整个
snapshot。自动测试不能完成升级。

## 2. 输出物

输出目录：`docs/partner-review/`

### 2.1 影视伙伴政策数据复核说明-v1.pdf

3–4 页中文 PDF，包含：

1. 项目目的、适用范围和 `mock_verified` 边界；
2. P0：p4 流程、p5 表单与材料；
3. P1：p2 特殊题材、p3 金额门槛；
4. P2：p1 定义、p6 条款与来源；
5. 回填方式、证据要求和升级条件。

首页及结尾均显示：“联调候选数据，未经完整人工复核，不构成法律意见。”

### 2.2 影视伙伴政策数据确认表-v1.xlsx

工作簿包含五个工作表：

1. `填写说明`：材料目的、状态定义、填写示例和交付要求；
2. `规则确认_p1-p3`：微短剧定义、九类特殊题材、真人和 AI 金额门槛；
3. `流程材料_p4-p5`：T1/T2/T3 步骤、责任人、必填字段和材料卡；
4. `条款来源_p6`：候选原文、URL、适用范围和生效时间；
5. `复核汇总`：以公式统计待确认、已确认、需修改、无法确认。

确认表的通用回填字段为：

- 优先级；
- Pack 和条目 ID；
- 当前候选值；
- 确认状态；
- 建议修改值；
- 适用地区和项目类型；
- `effective_from`；
- 依据类型；
- 来源链接或附件名；
- 复核人；
- 备注和边界案例。

确认状态使用固定选项：`待确认`、`已确认`、`需修改`、`无法确认`。
可回填单元格使用浅黄色；标题和只读候选值使用蓝灰色。金额和日期保留
可计算的数值、日期类型，不写成装饰性文本。

## 3. 数据来源与边界

内容从以下仓库文件生成：

- `policy/seed-snapshot-v2.yaml`；
- `docs/policy-v2-human-review-checklist.md`；
- 已确认的完整 mock v2 设计。

p6 中的 URL 原样作为“候选来源”写入表格。本次不联网重新判断网页是否
仍有效，也不把影视伙伴行业经验包装成法律条文。原始 YAML、TDD 计划、
云端配置和代码不包含在对外材料中。

## 4. 质量与验收

- PDF 无裁切、乱码或跨页断裂，手机和 A4 打印均可读；
- Excel 五个工作表均完成一次视觉渲染检查；
- 所有候选条目可以回溯到 v2 pack；
- 状态下拉和汇总公式有效，无公式错误；
- 所有待人工填写项初始为空或“待确认”，不得预先勾选已确认；
- PDF 与 Excel 对优先级、候选金额和复核边界的表述一致；
- 文件名稳定，不生成多份难以区分的最终版本。

## 5. 不在本次范围

- 联网验证政策内容；
- 将 snapshot 升级为 `human_verified`；
- 代影视伙伴填写确认结果；
- 云资源、Gate 5-b 或海外政策材料；
- 对外发送邮件或上传第三方平台。
