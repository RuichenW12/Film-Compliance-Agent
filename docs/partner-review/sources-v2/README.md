## 使用约束

- `raw/` 是下载时网页快照；线上页面后续可能变化。
- `text/` 便于比对、审阅和喂给模型，但法律核验应回看 `raw/` 与线上原文。
- 合入真实生产快照前，应把相关项从 `MOCK` 变更为带复核人、复核时间和来源版本的已确认状态。
